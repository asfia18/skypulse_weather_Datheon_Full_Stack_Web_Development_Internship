Use your own OpenWeatherMap key (optional)

The app already works without a key (it uses Open-Meteo). To use OpenWeatherMap instead, create a free account at openweathermap.org, copy your key from "API keys", and paste it here. New keys can take up to a couple of hours to start working.

Leave the box empty and press Save to go back to using no key.
